# Outreach Templates — mizhi-bot SaaS

## Strategy

Target: Small service business owners who manage bookings via WhatsApp.
Approach: Referral-warm → existing mizhi clients → WhatsApp groups → direct DMs.

Priority order:
1. **华人商户群** (Chinese merchant groups on WhatsApp/WeChat) — highest conversion
2. **苏里南本地商户** (Local Suriname businesses) — existing brand recognition
3. **Product Hunt / Indie Hackers** — global awareness

---

## Follow-Up Sequence

If no response after first message:

| Day | Action | Template |
|-----|--------|----------|
| D+0 | Initial outreach | Use templates above |
| D+3 | Gentle follow-up | "Hey, just bumping this — did you get a chance to think about it?" |
| D+7 | Value add | Share a specific stat or screenshot from existing client |
| D+14 | Last touch | "No worries if not interested! Here's a link if you ever need it → [landing page]" |
